# دليل الكود — GenAI City Copilot

هذا الدليل مولَّد تلقائياً من الكود. كل دالة في الملفات عليها هامش شرح بجانب سطرها (`# ...`). ابحث عن اسم الدالة بـ Ctrl+F داخل VS Code لتصل لها.

## كيف تتحرك المنصة؟

1. `app.py` يقرأ المستخدم (`auth.py`) ثم البيانات (`data_layer.py`) ويفلترها بالصلاحيات (`security.py`).
2. يرسم الشريط الجانبي (`views_shell.py`) ثم الواجهة الرئيسية والتبويبات (`views_public/staff/admin.py`).
3. أي سؤال للمساعد يمر على `ai_service.py` (نفس الصلاحيات)، والشخصيتان توني وسعيدان في `ui.py`.
4. الأزرار العائمة والصفحات المستقلة: `views_public.render_fab` و`views_pages.py`.

## أين أعدّل؟

| أريد تعديل | الملف |
|---|---|
| شكل الألوان والنجوم والشخصيتين | `ui.py` |
| كلام الشخصيتين | `ui.py` ← `_DIALOGUE` و`_REACT` |
| تعليمات المساعد وقواعده | `ai_service.py` ← `_system_prompt` |
| الموديل المستخدم | `.env` ← `OPENAI_MODEL_NAME` |
| صوت الرد | `.env` ← `OPENAI_TTS_VOICE` |
| الأدوار والصلاحيات | `security.py` و`auth.py` |
| صفحة للزوار | `views_public.py` |
| صفحة للموظفين | `views_staff.py` |
| صفحة للمدير | `views_admin.py` |

## روابط تهمّك والصفحات المستقلة
- كل رابط في «روابط تهمّك» وفي التذييل وفي فقاعات الشخصيتين يضغط زراً مخفياً اسمه `PG_xxx` (انظر `render_quick_links` في views_public.py) فيفتح الصفحة المطلوبة كصفحة مستقلة (`open_page`).
- أقسام التبويبات تُفتح بالصيغة `tab:كلمة` (مثل `tab:رأيك`)، ويعالجها app.py. لا تعتمد على نقر التبويب بجافاسكربت.
- `page_header` في views_pages.py يرسم زر الرجوع والعنوان ويمرّر الشاشة لبداية الصفحة.

## فلتر السرية
- في views_shell.py: `_FILTER_COLUMNS` يحوي «السرية»، و`_filter_options` يرتّب الخيارات (عام ← سري ← سري للغاية) من البيانات التي يحق للمستخدم رؤيتها فقط (الزائر لا يرى إلا «عام»).
